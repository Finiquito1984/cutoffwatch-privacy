# Privacy policy — CutoffWatch

Public privacy policy for the Chrome/Edge extension **CutoffWatch – Script Tag & Leftover Code Check for Shopify**, in English and Portuguese (Portugal).

Meant to be served with GitHub Pages (main branch, site root):

- English: https://finiquito1984.github.io/cutoffwatch-privacy/
- Portuguese: https://finiquito1984.github.io/cutoffwatch-privacy/pt/

The contact form uses the free [Web3Forms](https://web3forms.com) access key in `site-config.js`. The destination inbox is set only in the Web3Forms dashboard; do not put an email address in these files. The form shows only "Message sent" or "Not sent, try again".

## Publish (GitHub Pages)

1. Create a public GitHub repository named `cutoffwatch-privacy` under the Finiquito1984 account (GitHub UI, or `gh repo create Finiquito1984/cutoffwatch-privacy --public`).
2. Copy the contents of this folder (not the folder itself) to the repository root on `main`: `index.html`, `pt/index.html`, `styles.css`, `form.js`, `site-config.js`, `README.md`.
3. Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, folder `/ (root)` → Save.
4. After a minute, confirm https://finiquito1984.github.io/cutoffwatch-privacy/ loads; the Portuguese copy is at `/pt/`.

Do not publish a contact email on the page. The Chrome Web Store dashboard contact email stays off this site.
